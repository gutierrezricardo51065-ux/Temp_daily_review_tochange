# __Gradient Descent__

##    Context & Definition : 
* Gradient Descent is an iterative optimization algorithm applied during the Predictive Modeling phase of the data science lifecycle.
* The Aim is to find the optimal parameters of a machine learning model by gradually minimizing a cost function (such as Mean Squared Error, MSE) by moving downhill in the direction of the steepest slope.

##   Key Use Cases :
*  Scalability: Simpler and significantly faster than the Normal Equation on datasets with a large number of features.
*  Algorithm Versatility: Forms the foundation for Linear Regression, Logistic Regression, Support Vector Machines (SVM), and Backpropagation in Neural Networks.
*  Online Learning: Capable of updating model parameters incrementally as new data streams in.

## Algorithmic Workflow:
*  1) Define the Model: Establish the predictive formula (e.g., least squares with one feature).

*  2) Define the Cost Function: Set the optimization target (e.g., Mean Squared Error).

*  3) Initialize Parameters: Set deliberate or random initial starting values for the parameters.

*  4) Iterative Descent:

      Calculate partial derivatives with respect to each parameter using the Chain Rule.
      
      Set the Learning Rate to determine the step size.
      
      Update the parameters by stepping in the opposite direction of the gradient.
      
      Repeat until convergence (when no further improvement is made).

## Critical Factors & Challenges
*  Learning Rate Selection:

    Too small: Computationally inefficient, taking a long time to reach the optimum.
    
    Too large: Overshoots the minimum and fails to converge.

* Cost Function Topography: While convex functions (like MSE in linear regression) guarantee a single global minimum, non-convex functions risk getting trapped in local minima or plateaus.

* Feature Scaling: Running the algorithm on unscaled data significantly increases the convergence time.

## __Gradient Descent Variants__

* Batch Gradient Descent
    * Sample Size per Update: Entire dataset.
    * Advantages: Stable trajectories; faster than the Normal Equation.
    * Disadvantages: Computationally slow on large datasets.

* Stochastic GD (SGD)
    * Sample Size per Update: 1 random instance.
    * Advantages: Highly computationally efficient; enables online learning; helps escape local minima due to noise.
    * Disadvantages: Cost function bounces back and forth; approaches the optimum but never fully settles on it.
			
* Mini-Batch GD			
    * Sample Size per Update: Small random subset.
    * Advantages: High performance due to hardware optimization of matrix operations; balances speed and stability.
    * Disadvantages: Harder to escape local minima compared to pure SGD.
