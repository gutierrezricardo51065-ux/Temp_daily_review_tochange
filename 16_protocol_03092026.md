# __Ensemble Method__

##    Context & Definition : 
* Decision Tree: easy to interpret, but has a real weakness → high variance / overfits easily on its own.
* Fix: don't rely on one tree → combine many models together = Ensemble Method (like trees in a forest — each one different, working as a group).
* Theory behind it: Wisdom of Crowds → a group of diverse, independent opinions/models can outperform a single one.
* Definition: an Ensemble Method combines the predictions of multiple models to produce one final prediction that's more accurate and stable than any single model alone

* Algorithm : individual model that learns from data to make predictions (e.g. Decision Tree, Logistic Regression). In an Ensemble, each combined model is one algorithm.
* Bootstrap: sampling with replacement — draw a sample the same size as the original dataset, but some rows can repeat and others get left out. Used to give each model (e.g. each Random Forest tree) slightly different training data. The leftover, unused rows are the OOB (Out-of-Bag) samples, used for free validation.

##   Voting : 
how you combine several trained models' predictions into one final ensemble prediction.
* Hard voting → each model votes a class, majority wins (a simple vote, Doesn't matter if the model was 51% or 99% sure, it counts the same).
* Soft voting → each model gives probabilities, they're averaged, highest average wins (each model contributes how confident it is across all classes)
  
##   Calibrated probabilities :
Calibration is particularly useful when you care about reliable probabilities, not just the predicted class.

* Sigmoid (Platt scaling) – generally a good choice with smaller datasets.
* Isotonic regression – more flexible but generally requires more data.

## Random Forest:
* An ensemble of many Decision Trees (Bagging + one extra idea: random features at each split).
	1) Multiple bootstrap samples of the original dataset are created (with replacement).
	2) A separate tree is trained on each sample.
	3) At every split of every tree, only a random subset of features is considered (not all of them) — this is what makes it different from plain Bagging.
	4) Result: many trees that are different from each other → poorly correlated errors

## Prediction

* Classification → each tree votes a class, majority wins (hard voting).
* Regression → the trees' numerical predictions are averaged.

## Validation — OOB (Out-of-Bag) Error
* Each tree is tested on the data it did not get in its bootstrap sample (Out-of-Bag).
* Gives a performance estimate without needing a separate validation set.

## Evaluation
* Classification → Accuracy, Precision, Recall, F1, ROC-AUC.
* Regression → MAE, MSE, RMSE, R².
